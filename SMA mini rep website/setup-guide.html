Step 1 🌐
Create a Supabase Project

Supabase is a free, open-source Firebase alternative. Sign up and create a new project.

  • 1 Go to supabase.com and sign in / sign up
  • 2 Click "New project" from your dashboard
  • 3 Give it a name like foodhub-db
  • 4 Choose a strong database password and save it
  • 5 Select your nearest region and click Create project
Open Supabase Dashboard ↗
Step 2 🔑
Get Your API Keys

After your project is created, grab the Project URL and anon key from the Settings panel.

  • 1 Inside your project, click Settings (gear icon, left sidebar)
  • 2 Click API in the settings menu
  • 3 Copy Project URL — looks like https://xxxx.supabase.co
  • 4 Copy anon public key — starts with eyJh...
💡 Use the anon key (not the service_role key). The anon key is safe to use in frontend code.
Step 3 🗃️
Create the Orders Table

Run the SQL below in Supabase → SQL Editor → New query. This creates the orders table and sets up security policies so FoodHub can write to it.

-- Run this in Supabase → SQL Editor → New Query CREATE TABLE IF NOT EXISTS orders ( id uuid PRIMARY KEY DEFAULT gen_random_uuid(), session_id text NOT NULL, items jsonb NOT NULL, -- cart items array stored as JSON subtotal numeric(10,2), delivery_fee numeric(10,2) DEFAULT 30, taxes numeric(10,2), total_price numeric(10,2), status text DEFAULT 'confirmed', created_at timestamptz DEFAULT now() ); -- Enable Row Level Security ALTER TABLE orders ENABLE ROW LEVEL SECURITY; -- Allow anyone to insert new orders (visitors place orders without login) CREATE POLICY "Anyone can insert orders" ON orders FOR INSERT WITH CHECK (true); -- Allow anyone to read orders (needed for order confirmation) CREATE POLICY "Anyone can view orders" ON orders FOR SELECT USING (true);
📌 After running: go to Table Editor in the left sidebar and you should see the orders table appear.
Step 4 ✏️
Paste Your Keys into supabase.js

Open supabase.js in your code editor and replace the two placeholder values at the top of the file.

// supabase.js — lines 14–15 // BEFORE (placeholders) const SUPABASE_URL = 'YOUR_SUPABASE_URL'; const SUPABASE_ANON_KEY = 'YOUR_SUPABASE_ANON_KEY'; // AFTER (paste your real values) const SUPABASE_URL = 'https://xxxxxxxxxxxx.supabase.co'; const SUPABASE_ANON_KEY = 'eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...';
✅ Once saved, open your browser console after placing an order — you'll see ✅ FoodHub Order saved to Supabase! ID: …

👀 What to Expect After Setup
🛒
Order Placed
Every "Place Order" in FoodHub inserts a row into your orders table instantly.
📊
View Orders
Go to Supabase → Table Editor → orders to see all orders with timestamps, items, and totals.
🔍
Console Log
Open DevTools → Console. After placing an order you'll see a green ✅ confirmation with the order UUID.
📦
items Column
The items column stores the full cart as JSONB — you can query individual fields with SQL.
